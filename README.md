Project Architecture & Governance
Technical Overview

AmarBank is a high-fidelity financial decision-support utility engineered to bridge the gap between complex banking ecosystems and user-centric requirements. Built on a Zero-Dependency Vanilla Architecture, the platform prioritizes ultra-low latency, accessibility, and data privacy. The interface adheres to the Government Digital Service (GDS) design principles, utilizing an emerald-tinted visual language to resonate with the professional landscape of the Bangladesh financial sector.

Core Functionalities

Segmented Intelligence Matrix: Employs a multi-dimensional filtering logic that cross-references user demographics (Student, Salaried, Business, NRB) against institutional strengths.

Curated Institutional Directory: Features an expansive database of Bangladesh's leading scheduled banks, including specialized Shariah-compliant and digital-first entities.

Product Mapping: Automatically identifies optimal account tiers (e.g., Agami, Saadiq, TARA) and payment instruments (Amex, Visa Signature, Aqua Prepaid) based on real-time user input.

Infrastructure Insights: Provides granular data on nationwide ATM density, NPSB/RTGS integration, and agent banking availability.

Design Philosophy

The system is designed for "High-Trust" environments. By removing non-professional visual elements (emojis, decorative animations) and implementing a high-contrast Emerald & Gold palette, the application ensures WCAG-compliant accessibility while maintaining the authoritative tone required for financial services.
